# deckforge keyboard shortcuts

Shortcuts are ignored while typing in a text field. Press `?` in the app for the same list.

| Keys | Action |
| --- | --- |
| `Q` / `P` | Play / pause deck A / B |
| `A` / `L` | Cue deck A / B (hold) |
| `1`–`8` | Deck A hot cues (hold to preview; `Alt` deletes) |
| `Shift` + `1`–`8` | Deck B hot cues (hold; `Alt+Shift` deletes) |
| `Z` / `M` | Sync on/off, deck A / B |
| `W` `S` / `O` `K` | Tempo up/down 0.1%, deck A / B |
| `E` `D` / `I` `J` | Pitch bend up/down, deck A / B |
| `↑` `↓` | Move selection in the active browser pane |
| `←` / `→` | Load selected track to deck A / B |
| `Tab` | Switch browser focus (sidebar / tracks) |
| `/` | Search the library |
| `+` / `-` | Waveform zoom in / out (also mouse wheel over a waveform) |
| `F` | Toggle quantize |
| `X` | Beat FX on / off |
| `Shift` + `X` | Release Ascend (cuts on the next downbeat unless Release is set to Now) |
| `V` | Freeze (hold): Dub Tape, Halo |
| `B` | Throw (hold): Dub Tape; arms another Backwash swell |
| `⌘,` | Settings |
| `?` | Shortcut overlay |
| `Esc` | Close the topmost panel or overlay |

Mouse: hot cue pads delete with `Shift`-click or right-click; the SYNC button sets the master deck on long press or `Shift`-click; double-clicking a track loads it to the first free deck (`Shift` = deck A, `Alt` = deck B); drag tracks onto a deck or a playlist. Drag a scrolling waveform sideways to scrub forwards or backwards (a horizontal trackpad scroll does the same); click or drag the overview to seek. The eject button on each deck confirms first if the deck is playing.
